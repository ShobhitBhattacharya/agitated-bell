## 🚀 Quick Start

### 1. Run Development Server
```bash
npm.cmd run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### 2. Run Automated Test Suite
```bash
npm.cmd test
```

### 3. Build for Production
```bash
npm.cmd run build
```
